# 模拟盘日线策略确认与成交

日线策略自动交易采用完整扫描结果，不依赖盘中通知是否已触发。普通监控规则、分钟策略及手动即时单保持原有方式；盘中止损、止盈和移动止损继续实时评估。

| 模式／时点 | 行为 |
| --- | --- |
| 14:50（北京时间） | 预扫描，预热历史数据和矩阵，只保存候选，不下单 |
| 14:55 | 获取当日行情，完整重算买入信号、过滤、评分及排序，保存买入确认批次 |
| 14:57 | 检查账户、资金、持仓和重复操作后提交买入收盘订单；14:58 起不补单 |
| 盘后（全量同步后） | 全量同步及指标加工成功、仓库缓存刷新后，用权威日 K 重算收盘卖出信号及最大持有期并提交卖出订单，按当日收盘价撮合，随后执行结算 |
| 次日开盘模式 | 盘后全量同步及指标加工成功后，独立扫描并提交下一交易日开盘订单；实时行情确认当日开盘后，按原始开盘价加滑点和费用撮合，无须等待盘后 |

14:57 是买入订单提交时间，成交仍按最终收盘价加既定滑点和费用结算。收盘卖出不再使用 14:50／14:55／14:57 的盘中快照，而是在盘后全量同步成功后按权威日 K 重新确认，仍按当日最终收盘价撮合。14:55 的买入信号可能不同于完整收盘日 K，不能据此宣称与日 K 回测完全一致，也不代表券商实际成交保证。

日线策略买点使用 14:55／14:57 的确认流程；卖点（策略卖出信号及最大持有期）改由盘后同步数据确认。确认时资金和持仓只用于生成计划，提交前再次校验；未成交卖单不会提前释放资金或持仓名额。风险退出已占用同一持仓批次时，不再重复提交日线卖单。

## 状态与异常

- **已预扫 → 已确认 → 已提交 → 已成交**：14:55 不会显示为已下单，14:57 不会提前显示成交。
- 关闭自动执行时生成待人工确认操作；错过相应提交窗口后不能回填成交。盘后卖出在管道结算后确认时，会即时按信号日权威收盘价补结算，不顺延到次日收盘。次日开盘的截止时间按已有交易日历／本地交易日期确定，无法确认下一交易日时暂停提交。
- 行情日期错误、时间缺失、落后超过60秒、时间超前、历史数据或策略计算失败时，跳过该规则并展示原因，不沿用预扫描结果。
- 全量同步失败或未启用全量 A 股日 K 同步时，不确认新的收盘卖出及次日开盘信号。仍含盘中快照的日 K 或指标缓存不能用于盘后确认。
- 次日开盘撮合要求当日原始行情含有效开盘价、正成交量和不早于 09:30 的当日行情时间；不使用竞价指示价、前复权价或最新价替代开盘价。开盘后才下单或转排队的订单留到下一次开盘，待核对归属订单不撮合。缺行情时保留盘后正式日 K 兜底；重复轮询、重启和盘后结算不会重复记账。
- 批次、订单及成交记录保留信号日期、行情时间、确认时间、提交时间和批次关联；成交台账 CSV 同步导出这些字段。
- 批次按账户、规则、交易日、方向和标的去重，卖出另关联持仓批次；提交窗口内重启恢复和重试不会重复下单。

## 已有操作的切换

首次采用新流程时，撤销可明确归属日线策略的旧自动待成交单和待确认操作，随后重新扫描。历史成交、手动单和盘中风险退出保留。

带有日线策略归属信息、但无法确定自动操作来源的旧记录标记为“待核对归属”，暂停撮合并阻止新增交易；可在页面撤单或拒绝旧操作后等待重新扫描。不会根据猜测删除或执行这些记录。

确认批次保存在各模拟账户的 `daily_batches/` 下，沿用项目原子写入和模拟盘锁。策略参数、冻结版本文件及历史回测结果不因此改动。
