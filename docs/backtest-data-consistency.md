# 回测数据一致性

相同策略和页面参数并不足以保证结果相同，还必须使用同一份日线、复权因子、
复权后的行情和指数基准数据。全量分钟关闭不会统一这些日线数据。

## 数据更新规则

- 盘中当日日 K 是临时快照。收盘后，盘后管道必须经配置的日 K 数据源批量刷新，
  不能再用实时快照代替定稿日线；即使当天分区已存在，也要刷新。
- 日 K 或复权因子的请求分块失败必须传回管道，任务标记为部分失败。
  成功分块可保留，但不能把“有部分行写入”当作整次同步成功。
- 新增或修订复权因子后，应重算受影响股票的历史 enriched 数据。
  只复制最新一天的行情，无法修复历史复权价差。
- 单策略回测的已完成结果仅在 enriched 发布版本和指数基准文件版本未改变时复用。
  数据更新后重新计算；同一运行中的任务仍支持重连和取消。

## 跨环境核对和修复

1. 固定策略文件、保存参数、日期、费用、成交口径和仓位设置。
2. 比较第一笔差异交易的日期、数量及买卖价格，再核对当天日线和复权记录。
3. 选定一份已完成盘后同步的数据快照。先备份目标环境相关分区，再对齐当天日 K、
   指数基准、必要维表，以及新增复权事件涉及的历史 enriched 行。
4. 通过仓库的发布机制写入 enriched，使矩阵及已完成回测结果随版本失效。
   不删除整个数据目录或无关缓存。
5. 用相同条件重新回测，核对信号、完成交易、逐笔价格、净值及基准；不能只比较收益率。

诊断中的数据版本用于识别本环境缓存是否过期，包含文件元数据，不能作为跨机器的
内容相等证明。跨机器应比较实际内容或同一快照的文件校验值。
